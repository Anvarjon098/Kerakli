# Kerakli

Kerakli — kichik loyiha. Hozircha repozitoriyada loyihaning asosiy kodi mavjud emas, u bosqichma-bosqich rivojlantiriladi.

## Holat

Loyiha boshlang'ich bosqichda. Hozirda repozitoriyda faqat GitHub Actions orqali Claude yordamchisini ishga tushiruvchi workflow mavjud (`.github/workflows/claude.yml`).

## Foydalanish

Issue yoki Pull Request izohida `@claude` deb yozib, Claude'ga vazifa berish mumkin.

## Hissa qo'shish

1. Issue oching va g'oyangizni yozing.
2. Alohida branch yarating.
3. O'zgarishlarni Pull Request orqali yuboring.
